# Задание 1: Юнит-тесты для Stellar Burgers

## Описание проекта

Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers.

Веб-приложение: https://stellarburgers.education-services.ru

## Структура проекта

```
qa-python-project/
├── praktikum/              # Пакет с основным кодом программы
│   ├── __init__.py
│   ├── bun.py             # Модель булочки
│   ├── burger.py          # Модель бургера (основной класс)
│   ├── database.py        # База данных с доступными ингредиентами
│   ├── ingredient.py      # Модель ингредиента
│   └── ingredient_types.py # Константы типов ингредиентов
├── tests/                  # Тесты
│   ├── __init__.py
│   ├── test_bun.py        # Тесты класса Bun
│   ├── test_burger.py     # Тесты класса Burger (с моками)
│   ├── test_database.py   # Тесты класса Database
│   └── test_ingredient.py # Тесты класса Ingredient
├── requirements.txt        # Зависимости проекта
└── README.md              # Этот файл
```

## Реализованные тесты

### Класс Bun (8 тестов)
- Инициализация булочки с разными параметрами (параметризация)
- Получение названия и цены

### Класс Ingredient (9 тестов)
- Инициализация ингредиента с разными типами (параметризация)
- Получение типа, названия и цены

### Класс Database (10 тестов)
- Инициализация базы данных
- Получение списка доступных булочек
- Получение списка доступных ингредиентов
- Проверка типов и содержимого данных

### Класс Burger (26 тестов) - с использованием моков
- Инициализация бургера
- Установка булочки
- Добавление ингредиентов
- Удаление ингредиентов по индексу (параметризация)
- Перемещение ингредиентов (параметризация)
- Расчёт цены бургера (параметризация, моки)
- Формирование чека (моки)

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <URL репозитория>
cd Diplom_1
```

### 2. Создание виртуального окружения

```bash
python3 -m venv venv
source venv/bin/activate  # Для Linux/Mac
# или
venv\Scripts\activate  # Для Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск тестов

#### Запуск всех тестов
```bash
pytest
```

#### Запуск тестов с отчётом о покрытии
```bash
pytest --cov=praktikum --cov-report=term
```

#### Запуск тестов с HTML отчётом о покрытии
```bash
pytest --cov=praktikum --cov-report=html
```

После выполнения команды откройте файл `htmlcov/index.html` в браузере для просмотра детального отчёта.

#### Запуск тестов в verbose режиме
```bash
pytest -v
```

## Использованные техники

### Моки (Mock)
Использованы в тестах класса `Burger` для изоляции от зависимостей:
- Мокирование объектов `Bun` для тестирования методов `get_price()` и `get_receipt()`
- Мокирование объектов `Ingredient` для тестирования добавления, удаления и перемещения

### Параметризация (@pytest.mark.parametrize)
Применена для тестирования различных сценариев:
- Инициализация булочек с разными названиями и ценами
- Инициализация ингредиентов разных типов
- Удаление ингредиентов по разным индексам
- Перемещение ингредиентов между позициями
- Расчёт цены с разными комбинациями ингредиентов
